# ERRATA — Judge Video Script v0.2

**Target:** 85–95 seconds, one continuous product story, no slide-first opening.

## Shot order

### 0:00–0:10 — Problem

Screen already on the ERRATA operator surface.

Voiceover:

> Transit controllers correct themselves while they are already handling radio, maps and incident tools. A bad correction can create two conflicting operational truths.

Show the one-line invariant:

> ERRATA repairs the same change. It does not fork the truth.

### 0:10–0:30 — First spoken amendment

Start microphone. Speak:

> Route 55 west, skip King Edward and Cumberland until 9:30.

Keep the AssemblyAI partial/final transcript visible. Show the non-mutating preview first, then click **Apply spoken turn**.

On screen, make the viewer see:

- same `change_id`;
- rev1 → rev2;
- King Edward + Cumberland skipped;
- end 09:30;
- downstream consumer decodes the generated GTFS-RT bytes.

### 0:30–0:48 — Self-repair / signature moment

Speak the bounded bilingual correction:

> Wait — garde Cumberland. Make it 10.

Show:

- AssemblyAI EN/FR capture;
- same `change_id`;
- rev2 still canonical until Apply;
- Apply → rev3;
- Cumberland restored;
- King Edward still skipped;
- end 10:00;
- downstream decoded artifact changes.

Voiceover:

> The correction does not become a second instruction. It repairs the same versioned change.

### 0:48–1:02 — Negative path / ghost speech

Speak:

> Wait, keep Cumberland. Make it.

Show the clarification and **GHOST SPEECH · NOT CANONICAL · 0 effect · hash unchanged**.

Do not Apply.

Voiceover:

> Incomplete speech can be visible without becoming operational truth.

### 1:02–1:15 — Stale authority

Use an old reviewed hash. Show **REFUSED / STALE**.

Then use the current reviewed hash. Show **COMMITTED**.

Voiceover:

> Even a correct instruction cannot commit against an obsolete review.

### 1:15–1:27 — AssemblyAI depth

Briefly point to the live metrics/evidence:

- Universal-3.5 Pro Realtime;
- balanced mode;
- EN/FR steering;
- dynamic keyterms;
- `agent_context` / context updates;
- `SpeechStarted` barge-in only if the human proof has passed.

Voiceover:

> AssemblyAI owns live speech understanding. ERRATA keeps mutation authority deterministic and human-controlled.

### 1:27–1:32 — Close

Show the decoded GTFS-RT consequence beside the committed state.

Final line:

> Speech is fast and fallible. ERRATA keeps one operational truth.

## Optional phone cold-open

Use this only if the Twilio gate becomes PROVEN before filming.

Open with a real phone call for 4–6 seconds, then cut directly to the browser receiving the same signed-session amendment. Do not show or claim the phone path if the real-call proof has not passed.

## Do not put in the first 90 seconds

- Conditional Gateway Registry;
- Cloudflare history;
- internal gate names;
- architecture migration history;
- speculative TAM;
- unproven agency adoption;
- unproven production barge-in;
- unproven Twilio behavior.
