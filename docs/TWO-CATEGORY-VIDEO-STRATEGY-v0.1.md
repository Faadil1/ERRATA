# ERRATA — Two-Category Video Strategy v0.1

## Category A — /brag teaser

**Purpose:** launch/social/preview. It must create curiosity, not replace proof.

**Target duration:** 20–30 seconds.

### Structure

**0–4 s — Hook**
`A spoken correction should not create a second operational truth.`

**4–12 s — First wow**
Operator speaks Route 55 amendment.
Show live AssemblyAI transcript and rev1 → rev2.

**12–20 s — Signature repair**
`Wait — garde Cumberland. Make it 10.`
Show same `change_id`, rev2 → rev3.

**20–26 s — Trust moment**
Flash:
- GHOST SPEECH;
- 0 canonical effect;
- stale hash REFUSED.

**26–30 s — Close**
`Speech is fast and fallible. ERRATA keeps one operational truth.`

Rules:
- no architecture explanation;
- no internal gate vocabulary;
- no unsupported live/agency claims;
- captions must carry the story even muted.

## Category B — Egaki / Judge controlled demo

**Purpose:** judging, technical depth, reproducible proof.

**Target duration:** 105–120 seconds. Must exceed 90 seconds.

### Structure

**0–8 s — Problem / operator**
Transit controller correcting an active service change while already handling radio/maps/incidents.

**8–18 s — Product promise**
Show:
`same change_id · one operational truth · human Apply boundary`.

**18–42 s — Base live voice flow**
Speak:
`Route 55 west, skip King Edward and Cumberland until 9:30.`

Show:
- microphone;
- AssemblyAI U3.5 Pro Realtime;
- partial/final transcript;
- non-mutating preview;
- explicit Apply;
- rev1 → rev2;
- GTFS-RT downstream decode.

**42–66 s — Same-identity correction**
Speak:
`Wait — garde Cumberland. Make it 10.`

Show:
- EN/FR capture;
- rev2 remains canonical until Apply;
- same `change_id`;
- Apply;
- rev2 → rev3;
- Cumberland restored;
- King Edward remains skipped;
- end 10:00;
- downstream artifact changes.

**66–82 s — Negative path**
Speak:
`Wait, keep Cumberland. Make it.`

Show:
- clarification;
- GHOST SPEECH;
- 0 canonical effect;
- revision/hash unchanged.

**82–96 s — Authority / stale state**
Use stale reviewed hash → REFUSED.
Use current reviewed hash → COMMITTED.

**96–108 s — Sponsor depth**
Show only features actually proven on final runtime:
- AssemblyAI Realtime;
- keyterms;
- EN/FR steering;
- agent_context/context updates;
- balanced mode;
- barge-in only if human proof passed.

**108–116 s — Operational consequence**
Show decoded GTFS-RT and evidence receipt tied to current canonical state.

**116–120 s — Final line**
`Speech is fast and fallible. ERRATA keeps one operational truth.`

## Phone transport rule

Bandwidth may appear only if `Bandwidth Phone Transport = PROVEN`.

If proven, use it as a 5–8 second cold-open or a brief secondary proof. Do not let it displace the browser same-identity correction sequence.

## Claim firewall

Never show or narrate as proven unless the corresponding gate is proven:
- agency publication/adoption;
- production barge-in;
- external operator usage;
- Bandwidth phone flow;
- shared durable multi-operator state.
